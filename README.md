# Сайт Марины Вильдановой

Одностраничный лендинг на чистом HTML, CSS и JavaScript — без фреймворков и сборки.
Чтобы посмотреть сайт, просто откройте `index.html` в браузере.

## Что где лежит

| Файл | Что внутри |
|---|---|
| `index.html` | Главная страница: все блоки лендинга |
| `about.html` | Отдельная страница «Как я пришла в коучинг» (сюда позже добавим видео) |
| `css/styles.css` | Все стили. Цвета и шрифты — в самом начале файла, в блоке `:root` |
| `js/main.js` | Мобильное меню, подсветка разделов, плавное появление блоков |
| `images/` | Картинки. Сейчас там временная заглушка вместо фото |

## Блоки главной страницы (по порядку)

1. Первый экран — имя, кто я, кнопки, фото
2. Хук — боль клиента и цитата
3. Обо мне (`#about`)
4. С чем я работаю (`#topics`)
5. Подход (`#approach`)
6. Опыт и квалификация (`#experience`)
7. Форматы и стоимость (`#prices`)
8. Как начать (`#start`)
9. Контакты (`#contacts`)

В `index.html` каждый блок начинается с комментария вида `<!-- ============ 7. ФОРМАТЫ И СТОИМОСТЬ ============ -->`, так его легко найти.

## Частые правки

- **Поменять цену** — найти в `index.html` нужную карточку в блоке «Форматы и стоимость» и исправить число в `<span class="price">`.
- **Вставить фото** — положить файл в `images/` (например, `hero.jpg`) и заменить `images/photo-placeholder.svg` на `images/hero.jpg` в нужном `<img>`. Лучше всего подойдут вертикальные фото 4:5.
- **Добавить MAX** — в блоке контактов заменить `<span class="contact contact--soon">…</span>` на ссылку `<a class="contact" href="ССЫЛКА" target="_blank" rel="noopener">…</a>` и вписать номер вместо «скоро».
- **Поменять цвета** — исправить значения в `:root` в начале `css/styles.css`.
